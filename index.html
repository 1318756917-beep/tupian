平台接入范围与版权说明
  • 本项目已实现：Openverse、Wikimedia Commons 公开图片 API 搜索；返回结果会显示来源、原图/详情链接，以及 API 提供的作者和许可信息。
  • 快捷跳转但未抓取：小红书、站酷、Behance、Pinterest、古田路9号、Pentawards、Red Dot。当前使用这些平台的公开搜索/官网入口，不会绕过登录、验证码、反爬或访问权限。
  • 可继续接入：Unsplash 官方 API（需你申请 Access Key，并由服务端保管）；Behance 等平台须先确认官方 API 当前是否开放给你的应用。小红书/ Pinterest 的全站图片抓取不能承诺，需官方授权或合规数据接口。
  • 公开可见不代表可任意商用。下载或用于商业项目之前，请逐张核对许可、署名和平台条款。此工具默认展示来源链接，不把搜索结果自动保存为自有图库。
在线部署后，本页面通过 /api/search 请求服务端代理。若来源接口限流、暂时不可用或无匹配结果，会显示相应错误状态，不会用示例图填充。
